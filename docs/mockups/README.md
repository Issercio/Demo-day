# Maquettes Pivoine & Lilas

Prototype HTML cliquable pour l’évaluation Holberton (palette, typographie, desktop, mobile, parcours client et admin).

Ouvrir [`index.html`](index.html) dans le navigateur, ou le shop local : http://localhost:5000/maquettes/

Ce n’est pas le shop live. Les boutons enchaînent les écrans du scénario Marie / Camille. Les PNG dans `frames/` sont les cadres hi-fi.
